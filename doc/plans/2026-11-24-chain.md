## User decisions

- One fixed next site per branch (hash of seed, "area" and the number of branches, among unused areas), shown before buying.
- Restaurant upgrades (sign, music, tables, plates) do NOT apply to branches (kitchen only).
- Cap 3 branches. No close-branch command: an unprofitable open is refused.

## Design

- Test day: `openBranch` and `refitBranch` run ONE full headless day of the blueprint (`runTicks`, pantries paused for the last `CLOSING_SOON_TICKS`, like the harness player) and store `expected` {profit, sales, served, customers}.
- Nightly: net = round(expected.profit x noise / 100) - area rent, noise 90 to 110 from an FNV hash of seed, night, branch id and day (no RNG stream). Cost per night is O(branches) arithmetic.
- Determinism: the test day uses a fresh state with `rng = createRng(seed|branch|id)`, so the flagship streams are untouched. Inputs: blueprint, area, branch seed, flagship day, flagship `ratings` snapshot. Refit with an unchanged kitchen is refused ('blueprint unchanged').
- Test-day state: `createGame`, then buildings and tiles replaced by the blueprint, tier 'restaurant', `tierDay = day` (no critic), money 1,000,000, one synthetic upgrade carrying the area's demand (reuses `upgradeEffects`), goals off, no `branches` field (no recursion).
- Areas (content, provisional): Quiet suburb 80% / $60, College town 100% / $90, Riverside 110% / $110, Old town 120% / $140, Station square 140% / $190.
- Costs (constants, provisional): open = blueprint value + fee [$1,000, $2,000, $3,000]; refit = $250 + max(0, new value - old value); `BRANCH_MAX` 3; `BRANCH_NOISE_PERCENT` 10. Open refused when the test day shows net <= 0.
- No new Tier: the chain stage means `state.won === true`. `GoalDef.tier` becomes `Tier | 'chain'`.
- Chain goals: `branches-3` (open 3), `chain-profit` ($5,000 net in total, `state.chainProfit`), `chain-day` ($1,200 in one day: flagship profit plus branch nets of `lastDay`); the last two are done only in the summary phase. `checkChainWin` sets `chainWon`, phase 'won', event `chainWon`.
- Save: optional `branches`, `chainProfit`, `chainWon`, `DayStats.branches`. Old saves load, no version bump.
