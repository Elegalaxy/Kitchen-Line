# Seasons (restaurant tier)

Status: approved by the user on 2026-11-24 (restaurant tier only; any-time unlock and menu listing with orders only in season; four seasonal dishes plus the new ingredient pumpkin; branches feel the season through a small night ratio; menu cap stays 6).

Goal: four 7-day seasons (Spring, Summer, Autumn, Winter) cycle by day number. Each shifts pantry prices, taste weights and branch nights, and has one seasonal dish that customers only want in season. Pure function of the day: no RNG stream, no GameState field, no save change, RNG draw count and order unchanged. The stall tier and any run without `defs.seasons` behave exactly as before (hashes and fixtures identical).

Calendar: `seasonIndex(day) = floor((day - 1) / 7) % 4` (0 Spring, 1 Summer, 2 Autumn, 3 Winter), `SEASON_DAYS` = 7.

Rules: one commit per step after `npm run typecheck`, `npm run lint`, `npx vitest run --exclude src/harness/perf.test.ts`. Allowed status values: `todo`, `done`, `verified`.
